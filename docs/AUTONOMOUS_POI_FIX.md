# 自動經停搜索修復

## 問題與修復

頁面將“經過一家麵包店買麵包”提取成 `poi_name="bakery"`，而原有類別僅有咖啡店、餐廳和醫院，導致模型去地理編碼泛指類別，再要求用戶選擇具體門店。

新增 `bakery` 類別，明確 `poi_name` 只用於用戶實際指定的門店名稱。泛指類別作為具體店名時，後端要求模型修正提取；類別需求不能通過 `resolve_place` 或 `ask_user` 轉成指定門店確認。

Agent 可調用 `search_pois` 自主搜索類別或具體名稱。默認圍繞已取得的真實 OSRM 參考路線，最多采樣五個服務返回的路線頂點，一次 Overpass 查詢搜索候選；仍可根據結果決定搜索起點或終點附近。採樣範圍有限，不能聲稱窮盡所有沿途門店。候選的粗略距離篩選不代替 OSRM 分段算路，也不驗證到達時限。

麵包店查詢使用 OpenStreetMap 的 [`shop=bakery`](https://wiki.openstreetmap.org/wiki/Tag%3Ashop%3Dbakery) 標籤，查詢組合遵循官方 [Overpass QL](https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_QL)。保留真實 OSM 身份、位置及營業標籤，不用咖啡店冒充麵包店。

工具返回多個候選後，LLM 決定規劃哪些門店，後端計算和驗證實際路線。單個門店返回無路線時繼續其他候選；網絡、認證等服務錯誤仍如實報告。首批查詢為空或候選驗證失敗時允許擴大搜索，保持有限預算和原始約束。

買麵包預計停留多久、家庭／公司確切位置、是否有車等無法得知的個人事實仍需要確認。系統不會從出發到到達的剩餘時間推斷購物時長。公共交通業務經停仍是已有的能力限制，本次沒有聲稱解決。

## 驗證

- 瀏覽器重試用戶原文，頁面只詢問缺失的停留時間，並顯示“由系統選擇沿途麵包店”，不再要求門店地址。
- 真實地圖測試：Raffles City 至 Marina Bay Sands 的 OSRM 步行參考路線約 1.96 公里，Overpass 返回十個真實麵包店候選。此為公共地標測試，不是替用戶確認家庭／公司位置。
- 真實 Agent 測試記錄 `outputs/20261005T095106-e18f457b/result.json`：提供已核實的公共地標地點 ID，要求步行、沿途買麵包、停留五分鐘、一小時內到達；模型自主搜索十個麵包店，計算二十二條候選，通過驗證和比較選擇 Paris Baguette 方案，服務預計約三十一分鐘，全程沒有門店確認問題。耗時約九十一秒；模型曾出現兩次不符合當前狀態的工具調用，經後端反饋後繼續完成。單個測試不證明所有需求或實時條件均可滿足。
- 迴歸測試覆蓋泛指與店名的區分、真實標籤、參考路線證據、沿途採樣、自動比較多個門店、到達檢查、無法算路門店、首批空結果及營業失敗後的重新搜索和重規劃。

項目長期目標見 [PROJECT_GOALS.md](PROJECT_GOALS.md)，保持 Agent 的自主決策，避免針對示例固定所有工具調用。
