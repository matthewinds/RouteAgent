修复措施：

- `multiple_stops` 必须提供至少两个不同业务经停的准确、独立原文片段。起终点不算经停，同一家店的购物或吃饭按一次经停处理；真正多个业务经停仍按当前能力限制说明。
- 地点仍使用统一地图、别名和公开来源接口。网页来源对景点、酒店和其他地标开放；中文名称出现在连续中文原文中也可核验，拉丁名称保留完整词匹配限制。名称、来源引用与地图坐标仍分别校验，不维护环球影城或酒店地址表。
