# 地點提取與 LTA 狀態展示修復

本輪故障的原始記錄是 `outputs/20261005T145917-b90ef827/result.json`。用戶已提供“環球影城”起點、Hotel 1990 終點、麥當勞早餐和二十分鐘停留。首次提取漏掉必經地點的原文依據，被校驗拒絕；第二次提取修復了依據，卻遺漏起點字段，並把同一家麥當勞的早餐識別成多個業務經停。系統因此在地點搜索前就要求重新填寫起點，並沒有實際查詢環球影城。

修復措施：

- 模型修正需求提取時必須重交完整字段，不能丟掉起終點。後端保留此前有用戶原文支持的地點描述作為校驗提示，不自動填入或生成地點；已有地點依據卻設為空也被拒絕。提取尚未成功時不能繞過校驗直接向用戶提問。
- `multiple_stops` 必須提供至少兩個不同業務經停的準確、獨立原文片段。起終點不算經停，同一家店的購物或吃飯按一次經停處理；真正多個業務經停仍按當前能力限制說明。
- 地點仍使用統一地圖、別名和公開來源接口。網頁來源對景點、酒店和其他地標開放；中文名稱出現在連續中文原文中也可核驗，拉丁名稱保留完整詞匹配限制。名稱、來源引用與地圖座標仍分別校驗，不維護環球影城或酒店地址表。
- 網頁檢索階段可以攜帶查詢對象名稱；只有提交文檔或引用進行地址核驗時才要求完整證明。失敗響應提示如何修正查詢或引用，不能靜默更換用戶指定的地點。
- 網頁持續顯示 LTA 道路路況的調用狀態：需求／地點確認中尚未查詢、僅步行或公共交通未使用道路車速、查詢失敗、已採集記錄，或預約／歷史時段不適用。採集成功展示時間與記錄數；路線匹配及覆蓋仍以路線檢查為準。

本項目用 LTA DataMall 查詢實時道路車速區間、事故及停車信息，用 OneMap 查詢公交／地鐵組合行程。LTA 的實時觀測不是明早十點的預測路況；當前配置狀態也不代表本次查詢成功。參考 [LTA 動態數據說明](https://datamall.lta.gov.sg/content/datamall/en/dynamic-data.html)。

真實接口核對：中文“環球影城”直查未命中，`Universal Studios Singapore` 別名查詢返回真實主題公園以及附近入口等地圖候選。原始需求迴歸 `outputs/20261005T150602-0df32a2e/result.json` 保留“環球影城”，識別單次經停並進入真實查詢，而不是要求重新填寫起點。原來輸入的 Hotel 1990 與官網檢索到的 Hotel 1900 數字不同，已由用戶明確確認後者；不將這個名稱差異自行當成用戶許可。
