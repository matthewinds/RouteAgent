# 出行需求与结果修复记录

针对「从马来西亚新山入境新加坡的口岸去唐人街，希望经济实惠、尽快到达，并考虑天气」修复以下行为。

## 已完成

- 中文别名和描述性地点可通过语义搜索查询真实地图候选。保留用户原文；口岸歧义需要确认，不默认选择第一项。泛指口岸时过滤内部 Block 楼栋，合并重复街道候选。
- 经济、速度、天气偏好在解析和地点确认后继续保留。自驾需要明确确认车辆可用；出租车请求不能解释成自驾。
- 口岸地图位置不代表实际出关乘车点。确认表单要求核实已入境及实际出发位置；新加坡境内路线不计通关和跨境时间。
- 接入 OneMap 公交／地铁直达行程及服务返回的参考票价、实际分段几何、线路和时刻。候车及换乘等待计入总服务预计时间。缺失票价保持未知。
- 天气可以按基础预计行程时段提供参考，同时明确未知拥堵和延误未计入；不会用天气匹配结果补造实时到达时间。
- LTA 查询设置独立时间和调用上限，复用已取得的数据，并明确标注未完整读取及覆盖不足。
- 基础路线检查通过但费用、天气、完整时间或交通方式比较不完整时，只发布「参考方案／待核实」。页面展示未取得的交通方式，不再用综合分暗示所有需求已满足。

## 公共交通配置及范围

在本地 `.env` 设置 `ONEMAP_TOKEN`，可选覆盖 `ONEMAP_BASE_URL`。模板见 `.env.example`，接口定义见 [OneMap 官方 Routing 文档](https://www.onemap.gov.sg/apidocs/routing)。访问令牌只用于后端授权头，不放入网页表单和查询参数。

当前项目没有配置 OneMap 访问令牌，因此真实公交／地铁与票价验收尚未完成。适配器的响应协议、几何、时刻、费用和失败处理使用模拟响应测试，不能视为真实服务可用性证明。

公共交通支持起终点间行程，包括服务返回的换乘；尚不支持业务经停点、停车接驳、避高速等附加条件。遇到这些条件会明确返回能力限制，不会悄悄丢弃条件。出租车／网约车报价以及自驾燃油、过路费、停车总成本仍未知，因此无法证明所有方式中最便宜或全局最快。
