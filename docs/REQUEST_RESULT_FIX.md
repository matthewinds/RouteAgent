# 出行需求與結果修復記錄

針對「從馬來西亞新山入境新加坡的口岸去唐人街，希望經濟實惠、儘快到達，並考慮天氣」修復以下行為。

## 已完成

- 中文別名和描述性地點可通過語義搜索查詢真實地圖候選。保留用戶原文；口岸歧義需要確認，不默認選擇第一項。泛指口岸時過濾內部 Block 樓棟，合併重複街道候選。
- 經濟、速度、天氣偏好在解析和地點確認後繼續保留。自駕需要明確確認車輛可用；出租車請求不能解釋成自駕。
- 口岸地圖位置不代表實際出關乘車點。確認表單要求核實已入境及實際出發位置；新加坡境內路線不計通關和跨境時間。
- 接入 OneMap 公交／地鐵直達行程及服務返回的參考票價、實際分段幾何、線路和時刻。候車及換乘等待計入總服務預計時間。缺失票價保持未知。
- 天氣可以按基礎預計行程時段提供參考，同時明確未知擁堵和延誤未計入；不會用天氣匹配結果補造實時到達時間。
- LTA 查詢設置獨立時間和調用上限，複用已取得的數據，並明確標註未完整讀取及覆蓋不足。
- 基礎路線檢查通過但費用、天氣、完整時間或交通方式比較不完整時，只發布「參考方案／待核實」。頁面展示未取得的交通方式，不再用綜合分暗示所有需求已滿足。

## 公共交通配置及範圍

在本地 `.env` 設置 `ONEMAP_TOKEN`，可選覆蓋 `ONEMAP_BASE_URL`。模板見 `.env.example`，接口定義見 [OneMap 官方 Routing 文檔](https://www.onemap.gov.sg/apidocs/routing)。訪問令牌只用於後端授權頭，不放入網頁表單和查詢參數。

當前項目沒有配置 OneMap 訪問令牌，因此真實公交／地鐵與票價驗收尚未完成。適配器的響應協議、幾何、時刻、費用和失敗處理使用模擬響應測試，不能視為真實服務可用性證明。

公共交通支持起終點間行程，包括服務返回的換乘；尚不支持業務經停點、停車接駁、避高速等附加條件。遇到這些條件會明確返回能力限制，不會悄悄丟棄條件。出租車／網約車報價以及自駕燃油、過路費、停車總成本仍未知，因此無法證明所有方式中最便宜或全局最快。
