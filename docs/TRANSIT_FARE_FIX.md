# 經停及混合公共交通的完整票價

2026-10-10 修復：過去經停前後各有公共交通時，`transit_via` 一律將整程票價設為未知。OneMap 對包含非普通 MRT/LRT 的行程也可能返回 `info unavailable`；本次推薦包含 Sentosa Express，不能只查普通公交／地鐵票價。

## 實現

Agent 可調用統一工具 `get_transit_fares`，對最多三個已知完整候選查價。省略 ID 時取已生成公共交通中服务時間最短的三個，不生成新路線。缺少整程票價的正式推薦／備選在發布前必須嘗試查價；來源未覆蓋仍可發布透明的參考方案，不能聲稱費用完整。

票價使用 LTA 官網計算器的站點目錄及查詢後端，公交線路、方向與站序必須唯一匹配真實站碼；MRT/LRT 使用目錄支持的車站編號。價格和計費距離取自返回值，未使用路線幾何距離套價，未寫死票價表。

官方換乘規則取自 PTC，核對首末上車間隔、換乘次數、實際下車至上車間隔（包含步行、等待及購物停留）、同號／附屬公交、經停離站並重新進入同一車站。符合條件時向下一次官方查詢傳入服務返回的累積計費狀態；不符合時重置。連續服務行程中的同站軌道換乘合併查價，業務經停不合併。

對已辨識的 Sentosa Express 站碼及服務，單獨讀取營運方官網標準入島費；目前支持從 VivoCity 入島及來源明確的島內免費乘坐。其他方向／特殊服務在來源未核實時保持未知。金額由官方頁面解析，未填入固定 S$4。

默認是標明的成人交通卡標準票價参考，不推断个人优惠资格；时段优惠、通票与支付附加费不在此参考中。保留分段應計金額、計費行程、重置原因、來源和證據，頁面展示完整總價或已核實部分小計。任一費用缺失不得把小計當作總價。過期／缺失票價證據失效，不能用舊完整金額繼續比較。

LTA 計算器後端屬於官網使用的查詢服務，不是帶版本承諾的公開 DataMall API；其結構、可用性或站點覆盖變化時會保留明確缺口。每批查價預算 15 秒，為模型完成推薦保留時間，重複候選共享官方響應緩存。
