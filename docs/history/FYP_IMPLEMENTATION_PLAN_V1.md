# FYP 模块化实施计划

更新时间：2026-10-01（新加坡时间）。

## 目标与边界

将 MapAgent 的地理问答流程改造为新加坡出行路线规划系统：需求解析 → 按需工具调用 → 候选路线 → 约束验证 → 有限重规划 → 排序与解释。最终通过浏览器交互页面完成请求、澄清、查看地图、比较方案及导出记录。

首版：新加坡驾车、一个经停 POI、总时间约束、避堵和避高速。OSM/OSMnx 负责路径计算，LTA 负责交通证据；LLM 理解需求与选择动作，确定性程序负责数值计算和验证。步行、公共交通与天气为后续扩展。

## 接口与数据流

`plan_route(text, clarifications, context_mode, snapshot_id) -> PlanningResult`

统一使用 TravelRequest、ToolResult、RouteCandidate、CheckResult、TaskState、PlanningResult。内部时间为秒、距离为米，出发时间为 Asia/Singapore。路线保存有向路段 ID、完整几何、分段时间、停留、POI、来源、更新时间和交通覆盖率。

必须/不能/最多为硬约束；希望/尽量为软偏好。缺少起终点、交通方式或必要经停时长时澄清。总时间包含经停。通过/违反/未知分别显示；未知硬约束不算满足。预计到达只是当前模型与快照下的估计。

## 搜索、验证与排序默认规则

- 初次查询前 10 个 POI，失败扩大到前 30 个；每段最多 3 条替代路线。
- 优先级估计只决定搜索顺序；安全剪枝仅删除确定冲突，Top-K 截断记录为启发式限制。
- 首次规划加最多两次重规划；重复参数与快照复用缓存，重复状态提前结束。
- 原需求不被自动放宽。固定 POI 不替换为另一家；搜索失败仅表示当前范围未找到。
- 所有硬约束通过才推荐，未知路线另列为待核实。
- 时间/距离相对同请求直接基础路线归一化；拥堵为匹配路段的拥堵长度占比；不确定性为未知路段长度占比。
- 默认时间 0.7、距离 0.2、不确定性 0.1；明确避堵时：时间 0.5、距离 0.1、拥堵 0.3、不确定性 0.1。
- 未匹配或过期交通不表示畅通。低可信道路匹配拒绝；普通事故不能自动当作封路。
- 缺少实时服务凭据时使用明确标记的重放模式，真实接入保持未验收。

## 前端

Streamlit＋交互地图。本地浏览器提供自然语言输入、出发时间、示例、需求确认、补充澄清、阶段进度、路线切换、POI、指标、逐条约束和证据解释。后台线程与阶段事件避免阻塞页面。提供请求/结果 JSON 下载；修改条件可重新提交。密钥仅在服务端。

## 实验

20 条开发请求和 60 条固定测试请求分离；保存数据版本、模型、提示词、权重、快照和预测。对照包括基础最快路线、固定工具一次规划、完整系统、无验证、无重规划、无偏好排序、无粗筛。原 MapAgent 问答是独立旧基线，不冒称为路线实验的原样复现。

指标：字段与硬/软约束提取、约束满足率、未知率、可行方案找到率、重规划恢复率、候选保留率、排序质量、工具次数、延迟、解释证据一致性。合成测试仅验证机制；真实 OSM/LTA 场景结果独立报告。
