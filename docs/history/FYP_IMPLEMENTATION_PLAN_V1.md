# FYP 模塊化實施計劃

更新時間：2026-10-01（新加坡時間）。

## 目標與邊界

將 MapAgent 的地理問答流程改造為新加坡出行路線規劃系統：需求解析 → 按需工具調用 → 候選路線 → 約束驗證 → 有限重規劃 → 排序與解釋。最終通過瀏覽器交互頁面完成請求、澄清、查看地圖、比較方案及導出記錄。

首版：新加坡駕車、一個經停 POI、總時間約束、避堵和避高速。OSM/OSMnx 負責路徑計算，LTA 負責交通證據；LLM 理解需求與選擇動作，確定性程序負責數值計算和驗證。步行、公共交通與天氣為後續擴展。

## 接口與數據流

`plan_route(text, clarifications, context_mode, snapshot_id) -> PlanningResult`

統一使用 TravelRequest、ToolResult、RouteCandidate、CheckResult、TaskState、PlanningResult。內部時間為秒、距離為米，出發時間為 Asia/Singapore。路線保存有向路段 ID、完整幾何、分段時間、停留、POI、來源、更新時間和交通覆蓋率。

必須/不能/最多為硬約束；希望/儘量為軟偏好。缺少起終點、交通方式或必要經停時長時澄清。總時間包含經停。通過/違反/未知分別顯示；未知硬約束不算滿足。預計到達只是當前模型與快照下的估計。

## 搜索、驗證與排序默認規則

- 初次查詢前 10 個 POI，失敗擴大到前 30 個；每段最多 3 條替代路線。
- 優先級估計只決定搜索順序；安全剪枝僅刪除確定衝突，Top-K 截斷記錄為啟發式限制。
- 首次規劃加最多兩次重規劃；重複參數與快照複用緩存，重複狀態提前結束。
- 原需求不被自動放寬。固定 POI 不替換為另一家；搜索失敗僅表示當前範圍未找到。
- 所有硬約束通過才推薦，未知路線另列為待核實。
- 時間/距離相對同請求直接基礎路線歸一化；擁堵為匹配路段的擁堵長度佔比；不確定性為未知路段長度佔比。
- 默認時間 0.7、距離 0.2、不確定性 0.1；明確避堵時：時間 0.5、距離 0.1、擁堵 0.3、不確定性 0.1。
- 未匹配或過期交通不表示暢通。低可信道路匹配拒絕；普通事故不能自動當作封路。
- 缺少實時服務憑據時使用明確標記的重放模式，真實接入保持未驗收。

## 前端

Streamlit＋交互地圖。本地瀏覽器提供自然語言輸入、出發時間、示例、需求確認、補充澄清、階段進度、路線切換、POI、指標、逐條約束和證據解釋。後臺線程與階段事件避免阻塞頁面。提供請求/結果 JSON 下載；修改條件可重新提交。密鑰僅在服務端。

保留 `.git`、根目錄 `.env`、開發配置及原 `.venv`；新建獨立 `.venv-fyp`。舊基線置於 `baselines/mapagent`，保留文本/API 代碼、提示詞、數據、必要測試及復現記錄。

視覺、MapQA、舊輸出、未採用分支與臨時文件複製到 `F:\develop\archives\MapAgents\<時間戳>`。對每個文件檢查相對路徑、大小和 SHA-256；全部成功後才刪除源。刪除目標必須解析為當前項目下的明確白名單路徑，不跟隨鏈接。

## 實驗

20 條開發請求和 60 條固定測試請求分離；保存數據版本、模型、提示詞、權重、快照和預測。對照包括基礎最快路線、固定工具一次規劃、完整系統、無驗證、無重規劃、無偏好排序、無粗篩。原 MapAgent 問答是獨立舊基線，不冒稱為路線實驗的原樣復現。

指標：字段與硬/軟約束提取、約束滿足率、未知率、可行方案找到率、重規劃恢復率、候選保留率、排序質量、工具次數、延遲、解釋證據一致性。合成測試僅驗證機制；真實 OSM/LTA 場景結果獨立報告。
