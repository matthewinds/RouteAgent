## 網頁整體驗收

頁面通過後臺任務和階段隊列運行，頁面僅調用統一服務。程序集成測試與實際瀏覽器操作分別檢查：

| 流程 | 證據 |
|---|---|
| 輸入並獲得推薦、地圖 | 默認經停請求得到 15 分鐘總時間，含 5 分鐘經停；顯示 POI 和路線 |
| 頁面澄清並繼續 | 缺少模式/停留時顯示駕車與時長字段，提交後得到結果 |
| 首次失敗後重規劃 | `demo-replan` 首輪 10 個 POI 沒有通過，擴大至 30 後找到 Candidate Cafe 10；過程顯示重規劃 1 次 |
| 無可行方案 | 5 分鐘總上限、10 分鐘停留請求顯示“當前搜索範圍內未找到” |
| 證據不足 | `demo-unknown` 顯示待核實、交通覆蓋 0%、時間限制未知，不顯示正式推薦 |
| 方案選擇 | 選擇備選後更新選中方案與地圖 |
| 修改後重新提交 | 從澄清案例改成時間不足案例，顯示新的失敗結果 |
| 下載記錄 | 瀏覽器實際下載 JSON；用統一結果類型校驗，含需求、GeoJSON、逐項檢查和解釋 |

實際下載記錄：[web_export_example.json](validation/web_export_example.json)，其狀態為 `unverified`，正式推薦為空，含三個待核實方案；[web_replan_example.json](validation/web_replan_example.json) 保存了首次失敗、重規劃 1 次後獲得推薦的完整記錄。兩份文件均已通過類型與關鍵條件校驗。
